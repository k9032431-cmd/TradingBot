# 💎 Trading Desk — Telegram-бот для трейдера

Минималистичный бот с широкими экранами (баннер + цветные кнопки): автоимпорт сделок с Binance (через API-ключ Tiger.com), журнал прибыли/убытков, расходы, статистика, ценовые алерты, открытые позиции, курс монет и калькулятор позиции. Цветные кнопки (синие / зелёные / красные) и поддержка премиум-эмодзи.

## Возможности

| Раздел | Что делает |
|---|---|
| 🔗 Binance (Tiger) | Подключение по API-ключу **только для чтения**. Импорт сделок за 30 дней, дальше — автоматически каждую минуту с уведомлением «Сделка закрыта». Комиссии и фандинг попадают в расходы |
| 📍 Позиции | Открытые фьючерсные позиции: сторона, плечо, вход → маркировочная цена, P&L и ROE, цена ликвидации |
| 🟢 Прибыль / 🔴 Убыток | Запись сделки: сумма, пара, комментарий. Быстрый ввод без меню: `+150 BTC пробой`, `-40 ETH стоп` |
| 💸 Расход | Комиссии, фандинг, подписки, софт/VPS, обучение — по категориям |
| 💰 Депозит / вывод | Меняет баланс, но не влияет на P&L |
| 📊 Статистика | Сегодня / неделя / месяц / всё время: чистый P&L, винрейт, профит-фактор, средняя прибыль/убыток, лучшая/худшая сделка, результат по парам, расходы по категориям |
| 📒 История | Все записи постранично, удаление в один тап, экспорт в CSV (открывается в Excel) |
| 🔔 Алерты | Цена или проценты: `70000`, `+5% -3%`, несколько уровней сразу. Бот сам определяет направление и пишет, когда цена дошла |
| 📈 Курс | Цена с Binance Futures (как в Tiger Trade) с точностью шага цены пары, изменение за 24ч, максимум/минимум, объём. Если пары нет на фьючерсах — спот |
| 🧮 Калькулятор | Размер позиции по риску: `1000 1 65000 64000 68000` → объём, плечо, R:R |
| ⚙️ Настройки | Валюта учёта, стартовый баланс, экспорт, очистка данных |

Команды: `/menu`, `/pos`, `/alert BTC 70000`, `/p ETH`, `/export`, `/emoji`, `/id`, `/help`.

## Установка на VPS одной командой

Ubuntu 20.04+ / Debian 12+, зайди на сервер по SSH и выполни:

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/k9032431-cmd/TradingBot/HEAD/install.sh)"
```

> Именно так, а не `curl ... | sudo bash`: в Ubuntu 25.10+ (sudo-rs) при таком запуске скрипт не получает ввод с клавиатуры.

Скрипт поставит Python и зависимости, спросит токен бота (и сразу проверит его в Telegram), твой Telegram ID и часовой пояс, включит автозапуск (systemd) и проверит, доступен ли Binance с этого сервера. Повторный запуск той же команды — обновление (данные и ключи сохраняются).

Управление ботом на сервере:

| Команда | Что делает |
|---|---|
| `tbot status` | работает ли бот |
| `tbot logs` | логи в реальном времени (выход — Ctrl+C) |
| `tbot restart` | перезапуск |
| `tbot update` | обновить до последней версии (покажет, что нового) |
| `tbot config` | изменить настройки (.env) и перезапустить |

Бот ставится в `/opt/tradingbot`, база — `/opt/tradingbot/data/` (её и стоит бэкапить).

## Запуск вручную (на своём ПК)

1. Создай бота у [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Установи Python 3.10+ и зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Скопируй `.env.example` в `.env` и вставь `BOT_TOKEN`.
   Чтобы ботом мог пользоваться только ты — впиши свой ID в `ALLOWED_USERS` (узнать: команда `/id`).
4. Запусти:
   ```bash
   python -m bot.main
   ```

Данные хранятся локально в SQLite (`data/trading.db`). Бот должен работать постоянно, чтобы алерты срабатывали — запусти его на VPS или на своём ПК.

## Подключение Binance через Tiger.com

1. Зайди на **account.tiger.com/api** → «Новый API-ключ».
2. Права — **только «Права на чтение»**. Ключ с правами на торговлю или вывод бот не примет.
3. В боте: «Подключить Binance (Tiger)» → отправь ключ и секрет одним сообщением (две строки). Бот сразу удалит это сообщение; секрет хранится в базе зашифрованным (`data/secret.key` или `ENCRYPTION_KEY`).
4. Если включена привязка ключа к IP — добавь IP сервера, где запущен бот.

Как считается журнал:
- исполнения по одной паре с паузой меньше минуты склеиваются в одну сделку (P&L — реализованный, без комиссий);
- комиссии и фандинг пишутся отдельной строкой за день в категории «Комиссии» / «Фандинг»;
- учитываются USDT-M фьючерсы; спот показывается только как баланс.

> Binance не работает с серверов в некоторых странах (например, США). Запускай бота там, откуда Binance доступен, — на своём ПК или VPS в Европе/Азии.

## Премиум-эмодзи

По умолчанию бот использует обычные эмодзи. Чтобы поставить анимированные премиум-эмодзи (как в боте со скриншота):

1. Отправь боту `/emoji`, затем сообщение с нужными премиум-эмодзи — бот вернёт их ID.
2. Скопируй `emoji.example.json` в `emoji.json` и впиши ID напротив нужных ключей (`profit`, `loss`, `alert`, …).
3. Перезапусти бота. Эмодзи появятся и в сообщениях, и иконками на кнопках.

> Telegram показывает премиум-эмодзи от бота, только если у владельца бота есть Telegram Premium. Если что-то не отображается — очисти `emoji.json`, бот вернётся к обычным эмодзи.

## Цвета кнопок

Используется поле `style` кнопок Bot API: `success` — зелёный (прибыль, создать), `danger` — красный (убыток, удалить), `primary` — синий (разделы). Цвета задаются в `bot/ui.py`.

## Баннер

Картинка над экранами — `assets/banner.png`. Пересоздать: `python tools/make_banner.py` (или положи свою картинку ~1280×440 с тем же именем).

## Структура

```
bot/
  main.py        запуск, middleware доступа, фоновая проверка алертов
  config.py      настройки из .env
  db.py          SQLite (сделки, расходы, алерты)
  binance.py     Binance API (подпись запросов, баланс, позиции, доходы)
  sync.py        импорт сделок/комиссий/фандинга в журнал
  crypto.py      шифрование API-секретов
  prices.py      цены Binance: фьючерсы, затем спот; точность по шагу цены пары
  ui.py          эмодзи, цветные кнопки, форматирование
  handlers/
    common.py    /start, меню, /emoji, /help
    journal.py   прибыль / убыток / расходы / история / экспорт
    stats.py     статистика
    alerts.py    алерты + фоновый воркер
    tools.py     курс, калькулятор, настройки
    exchange.py  подключение Binance, позиции, фоновая синхронизация
```
